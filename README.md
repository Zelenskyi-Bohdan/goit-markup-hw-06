Web Studio

About the project:
Web Studio is a responsive web application (landing page) for an organic food store. The project was developed by me as part of a training course. The main focus is on semantic versioning and mobile-adaptive design.

Technology stack:
- HTML5 / CSS3 (semantics, Flexbox, CSS variables, Responsive Web Design, SVG).

Project structure:
- css/ — style files.
- img/ — static images.
